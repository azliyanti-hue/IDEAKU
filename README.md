# 📺 Media Prima Deck Studio AI — Omnia Pitch Architect

> **Aplikasi pintar penjana slaid cadangan penajaan televisyen dan digital untuk Media Prima Omnia dalam masa kurang 2 saat.**

Selamat datang ke **Media Prima Deck Studio AI**! Aplikasi ini direka khas untuk memudahkan pasukan jualan (*sales*), perancang media (*media planners*), dan jurustrategi komersial di Media Prima menghasilkan slaid pembentangan (*pitch deck*) penajaan yang lengkap, profesional, dan sedia untuk dibentangkan kepada klien dalam sekelip mata.

---

## 💡 Kenapa Aplikasi Ini Dicipta? (Masalah Yang Selesai)

* **Cara Lama**: Sebelum ini, pasukan jualan terpaksa menghabiskan masa berjam-jam membuka fail PowerPoint kosong, mencari data rating penonton, mengira kadar harga (*rate card*), dan menaip ayat cadangan satu persatu.
* **Cara Baharu**: Dengan aplikasi ini, anda hanya perlu masukkan nota ringkas klien (atau pilih sampel siap sedia), pilih saluran seperti **TV3** atau **TV9**, dan tekan satu butang. Enjin Kecerdasan Buatan (AI) akan menyusun **7 slaid pembentangan bernisbah 16:9** yang lengkap dengan data penonton, idea segmen kreatif, dan pakej harga!

---

## ✨ Ciri-Ciri Utama Yang Menarik

### ⚡ 1. Penjanaan Dek Pantas (<2 Saat)
Hanya tampal kehendak klien dan pilih saluran. Enjin AI pintar (Google Gemini) akan memproses strategi pemasaran dan menghasilkan set slaid pembentangan lengkap serta-merta.

### 📺 2. Pilihan Saluran TV3 & TV9 Lengkap
* **Rancangan TV3 Popular**:
  * *Wanita Hari Ini (WHI)* — Bual bicara santai wanita & masakan tengah hari.
  * *Malaysia Hari Ini (MHI)* — Program pagi seisi keluarga & gaya hidup.
  * *Buletin Utama (BU)* — Berita nombor satu negara waktu perdana.
  * *Melodi* — Berita hiburan nombor satu Ahad tengah hari.
  * *Nona* — Majalah wanita, fesyen & perniagaan.
* **Rancangan TV9 Mesra Keluarga**:
  * *Nasi Lemak Kopi O (NLKO)* — Rancangan pagi hujung minggu kegemaran keluarga.
  * *Berita TV9* — Berita petang padat untuk seisi rumah.
  * *Keluarga Kita* — Slot petang santai bersama anak-anak.
  * *Drama Santai TV9* & *Kapsul Famili*.
* **Slot Baharu (*+ New Program*)**: Anda juga boleh memasukkan nama program baharu atau siaran rintis (*pilot show*) mengikut keperluan semasa.

### ✏️ 3. Sunting Teks Terus Pada Slaid (*Inline Editing*)
Tekan butang **"Enable Inline Editing"** di bar atas. Anda boleh klik pada mana-mana tajuk, perenggan, atau angka di atas slaid untuk menukar perkataan mengikut kesesuaian. Semua perubahan akan disimpan secara automatik!

### 🔒 4. Log Masuk & Simpanan Awan (*Firebase Cloud Firestore*)
* **Log Masuk Google**: Log masuk dengan akaun Google anda untuk menyimpan semua cadangan ke pelayan awan Google Firebase secara masa nyata (*real-time*).
* **Buka Di Mana-mana Sahaja**: Cadangan yang disimpan dalam akaun boleh dibuka semula pada komputer riba, tablet, atau komputer pejabat.
* **Mod Luar Talian (*Guest Mode*)**: Anda tetap boleh menggunakan aplikasi ini tanpa log masuk — data akan disimpan dalam pelayar komputer anda (*LocalStorage*).

### 🖥️ 5. Mod Pembentangan Skrin Penuh (*Presentation Mode*)
Tekan butang **"Presentation Mode"** untuk memaparkan slaid dalam skrin penuh berkualiti tinggi (16:9) semasa mesyuarat bersama klien:
* Gunakan butang anak panah papan kekunci (`←` / `→` atau `Space`) untuk beralih slaid.
* Dilengkapi **Nota Juru Strategi (*Speaker Notes*)** yang boleh dibuka dengan menekan huruf `N` untuk melihat poin-poin penting semasa bercakap dengan klien.

### 🖨️ 6. Cetak & Eksport PDF (*Cetak / PDF*)
Satu klik untuk mencetak semua 7 slaid atau memuat turunnya sebagai dokumen fail PDF yang kemas dan beresolusi tinggi untuk diserahkan kepada pihak pengurusan atau klien.

### 📊 7. Hab Kad Kadar & Kalkulator Jangkauan (*Rate Cards & GRP*)
Buka tab **Rate Cards & Inventory** untuk melihat senarai harga iklan rasmi Media Prima bagi TV3, TV9, 8TV, Tonton, SirapLimau, dan Hot FM. Termasuk kalkulator automatik untuk mengira anggaran tontonan (*Gross Rating Points & CPM*) berdasarkan bajet klien.

## 📑 Struktur 7 Slaid Yang Dihasilkan

Setiap cadangan disusun mengikut piawaian industri penyiaran korporat Media Prima:

| Slaid | Tajuk Slaid | Penerangan Ringkas |
| :---: | :--- | :--- |
| **01** | **Title & Concept Hook** | Muka depan pembentangan dengan jenama Media Prima Omnia, tajuk kempen yang memikat, sasaran penonton, dan kod cadangan. |
| **02** | **Strategic Diagnostics** | Penerangan cabaran pasaran klien, data tontonan televisyen (TAM Nielsen), dan penyelesaian holistik Omnia. |
| **03** | **Program Spotlight** | Profil rancangan pilihan (cth. WHI / NLKO TV9 / MHI) berserta bilangan penonton bulanan, demografi, dan kredibiliti hos televisyen. |
| **04** | **Creative Integrations** | 4 idea segmen siaran menarik: demonstrasi masakan langsung, paparan grafik bertindih (*Aston banner & QR code*), penjenamaan set studio, dan video pendek di media sosial (TikTok & SirapLimau). |
| **05** | **Tactical Deliverables** | Jadual inventori siaran lengkap yang memperincikan kekerapan siaran dan jaminan jumlah tontonan (*impressions*). |
| **06** | **3-Phase Flight Timeline** | Jadual penerbangan kempen 8 minggu yang terbahagi kepada 3 fasa: Fasa Pengenalan (*Teaser*), Fasa Kemuncak (*Peak Surge*), dan Fasa Perayaan (*Finale*). |
| **07** | **Commercial Packages** | 3 pilihan pakej pelaburan (Pakej Utama A, Pakej B, dan Pakej C) berserta butang kunci tempahan slot (*Booking Lock*). |

## 🚀 Panduan Mudah Menggunakan Aplikasi (Untuk Pengguna Baharu)

1. **Buka Aplikasi**: Buka pautan aplikasi di pelayar web anda (Google Chrome disyorkan).
2. **Log Masuk (Pilihan)**: Klik butang **"Log Masuk"** di bahagian atas kanan untuk menyimpan dek anda ke akaun Google secara selamat.
3. **Pilih Sampel atau Tulis Sendiri**:
   * Untuk cuba serta-merta, klik butang sampel pantas: **F&N Susu (WHI)**, **TV9 Famili Sample**, **Milo (MHI)**, atau **Petronas (BU)**.
   * Atau taip ringkasan kehendak klien dalam kotak teks besar.
4. **Pilih Saluran & Rancangan**: Pilih saluran (**TV3** / **TV9**) dan rancangan pilihan anda (cth: *Nasi Lemak Kopi O*, *Wanita Hari Ini*, atau pilih *+ New Program*).
5. **Jana Slaid**: Klik butang merah **"Generate 7-Slide Deck"**. Dalam 2 saat, semua slaid siap dihasilkan!
6. **Semak & Bentang**:
   * Klik tab **"All 7 Slides Grid"** untuk melihat kesemua slaid sekali gus.
   * Klik **"Presentation Mode"** apabila bersedia untuk membentang di hadapan klien.
   * Klik **"Cetak / PDF"** jika ingin mencetak atau menyimpan dokumen fizikal.

## 🛠️ Maklumat Teknikal (Untuk Pasukan IT & Pembangun)

Aplikasi ini dibina dengan piawaian teknologi moden berasaskan web:

* **Antara Muka (Frontend)**: React 19, TypeScript, Tailwind CSS v4, Motion.
* **Pelayan Backend**: Node.js, Express, TSX.
* **Kecerdasan Buatan (AI Engine)**: Google GenAI SDK (`@google/genai`) dengan model pantas `gemini-3.8-flash`.
* **Pangkalan Data & Pengesahan**: Google Firebase (Authentication & Cloud Firestore) yang ditempatkan di rantau `asia-southeast1`.
* **Peraturan Keselamatan**: Dilindungi dengan *Firestore Zero-Trust Rules* berprinsip kawalan akses berasaskan peranan (RBAC).

### Menjalankan Aplikasi Secara Tempatan (Local Development):

```bash
# 1. Pasang semua pakej keperluan
npm install

# 2. Jalankan pelayan pembangunan (port 3000)
npm run dev

# 3. Bina fail pengeluaran (Production Build)
npm run build
```
